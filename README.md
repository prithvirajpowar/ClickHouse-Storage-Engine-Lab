# Project Overview

This repository demonstrates hands-on implementation and analysis of ClickHouse storage engines and performance optimization techniques.

The project focuses on understanding how ClickHouse stores data, merges parts, optimizes queries, and manages storage efficiently.

Topics covered include:

- MergeTree Family
- ReplacingMergeTree
- SummingMergeTree
- AggregatingMergeTree
- Materialized Views
- Projections
- Skip Indexes
- TTL
- Async Inserts
- Merge Process
- Query Optimization

---

# Objectives

- Study ClickHouse storage internals
- Compare MergeTree variants
- Implement projections
- Create materialized views
- Analyze query performance
- Optimize storage layout
- Understand asynchronous inserts
- Learn production best practices
